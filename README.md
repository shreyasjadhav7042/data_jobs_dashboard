# 📊 Data Jobs Dashboard – Power BI

## 📌 Overview

The **Data Jobs Dashboard** is an interactive Power BI project designed to explore trends in the data job market. It provides insights into salary variations, job role comparisons, in-demand technical skills, and salary distributions across data-related careers.

The dashboard presents key information through visualizations, making it easier to understand hiring trends and identify the skills valued in the data industry.

## 🎯 Objectives

- Analyze average salaries across different data job roles.
- Identify the most in-demand skills in the data industry.
- Compare job roles based on salary and other available metrics.
- Explore salary distributions and variations.
- Present data job market insights through interactive visualizations.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and data visualization.
- **Data Visualization** – Charts, graphs, and interactive reports.

## 📈 Key Features

### 1. Average Salary by Job Role
Visualizes average salaries across different data-related positions to help compare earning potential.

### 2. In-Demand Skills Analysis
Highlights the most frequently required skills in data-related job postings, helping identify important technical skills for career development.

### 3. Job Role Comparison
Enables comparisons between different job roles based on the metrics available in the dataset.

### 4. Salary Distribution Analysis
Explores salary variations across the data job market to provide a better understanding of compensation trends.

### 5. Interactive Dashboard
Provides an interactive interface for exploring visualizations and understanding the data through different perspectives.

## 💡 Key Insights

The dashboard focuses on identifying:

- Differences in average salaries across data job roles.
- Technical skills frequently required by employers.
- Salary variations between different positions.
- Patterns and trends within the data job market.

*The specific findings depend on the dataset and filters selected in the dashboard.*
